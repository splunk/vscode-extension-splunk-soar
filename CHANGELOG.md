## [0.0.35] - 2026-11-19

### Fixed

- Upgrade axios, follow-redirects, fast-uri, and packaging dependencies to patched versions.

- Upgrade Babel, ESLint, webpack tooling, and the documentation video player.
- Pin GitHub Actions to commit SHAs and the CI runner to Ubuntu 24.04.
